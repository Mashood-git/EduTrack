# 🎓 EduTrack

> **An AI-Powered Learning Platform built with Flask, SQLite, HTML, CSS, and JavaScript.**

EduTrack is a modern web application designed to provide an interactive learning experience for students while giving administrators a powerful dashboard to manage learners efficiently. The project focuses on clean UI, responsive design, and scalable architecture.

---

## ✨ Features

### 👨‍🎓 Learner Module
- User Registration
- Secure Login *(Coming Soon)*
- Personalized Dashboard *(Coming Soon)*
- Learning Progress Tracking *(Coming Soon)*

### 👨‍💼 Admin Module
- View All Learners
- Add New Learners
- Edit Learner Information
- Delete Learners
- Search Learners
- Dashboard Statistics
- Export Learner Data to CSV

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Mashood-git/EduTrack.git
```

### 2. Navigate to the Project

```bash
cd EduTrack
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Browser

```
http://127.0.0.1:5000/
```
