1. Introduction to Java

Java is a high-level, object-oriented programming language developed by James Gosling at Sun Microsystems and released in 1995. It follows the principle "Write Once, Run Anywhere (WORA)".

⭐ Key Points

  • Platform Independent
  • Object-Oriented
  • Secure and Robust
  • Supports Multithreading
  • Widely used for Web, Mobile and Enterprise Applications

💻 Example


public class Main {

    public static void main(String[] args) {

        System.out.println("Hello Java");

    }

}

🎯 Interview Question

Q. Who developed Java?
Answer: James Gosling.

2. Features of Java

  • Simple
  • Object-Oriented
  • Platform Independent
  • Secure
  • Robust
  • Portable
  • Multithreaded
  • Distributed
  • High Performance
  • Dynamic
💡 Tip

Java programs are compiled into bytecode, which runs on the JVM. This makes Java platform independent.

🎯 Interview Question

Q. Why is Java platform independent?
Answer: Because Java code is compiled into bytecode, which runs on any operating system that has a JVM.

3. JVM, JRE & JDK

These are the core components required to develop and run Java programs.

Component Description
JVM Runs Java bytecode.
JRE Provides libraries and JVM to run Java programs.
JDK Contains JRE + development tools like javac.

💻 Diagram


JDK
 ├── JRE
 │     └── JVM
⚠ Important

You need JDK to develop Java applications. You only need JRE to run Java applications.

🎯 Interview Question

Q. Difference between JVM, JRE and JDK?
Answer: JVM executes bytecode. JRE provides the runtime environment. JDK contains JRE along with development tools.

4. Variables

A variable is a named memory location used to store data. In Java, every variable must be declared with a data type before use.

⭐ Rules

  • Must be declared before use.
  • Cannot start with a number.
  • Case-sensitive (age and Age are different).
  • Use meaningful variable names.

💻 Example


int age = 22;

String name = "Mashood";

double salary = 45000.50;

boolean isStudent = true;
💡 Tip

Use camelCase for variable names. Example: studentName, totalMarks

🎯 Interview Question

Q. Why should variables be declared with a data type?
Answer: Because Java is a statically typed language. The compiler must know the data type before compilation.

Q. Difference between Primitive and Non-Primitive Data Types?
Answer: Primitive types store actual values. Non-Primitive types store references to objects.

6. Operators

Operators are symbols used to perform operations on variables and values.

⭐ Types of Operators

  • Arithmetic (+, -, *, /, %)
  • Relational (==, !=, >, <, >=, <=)
  • Logical (&&, ||, !)
  • Assignment (=, +=, -=)
  • Unary (++, --)
  • Ternary ( ? : )

💻 Example


int a = 10;

int b = 5;

System.out.println(a + b);

System.out.println(a > b);

System.out.println(a % b);
⚠ Important

Do not confuse: = → Assignment == → Comparison

🎯 Interview Question

Q. Difference between = and ==?
Answer: = assigns a value to a variable. == compares two values.

7. Input & Output

Java uses the Scanner class to accept input from the user and System.out.println() to display output.

💻 Example


import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter your age: ");

        int age = sc.nextInt();

        System.out.println("Age = " + age);

    }

}
💡 Tip

Always import the Scanner class before using it. import java.util.Scanner;

🎯 Interview Question

Q. Which class is used for user input in Java?
Answer: Scanner class.

8. Conditional Statements

Conditional statements execute different blocks of code depending on whether a condition is true or false.

⭐ Types

  • if
  • if-else
  • if-else-if ladder
  • switch

💻 Example


int marks = 75;

if(marks >= 35){

    System.out.println("Pass");

}else{

    System.out.println("Fail");

}

💻 Switch Example


int day = 2;

switch(day){

    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    default:
        System.out.println("Invalid Day");

}
⚠ Important

Always use break inside switch to avoid fall-through.

🎯 Interview Question

Q. What happens if break is omitted in a switch statement?
Answer: Execution continues to the next case until a break or the end of the switch block is reached.

9. Loops

Loops are used to execute a block of code repeatedly.

⭐ Types

  • for loop
  • while loop
  • do-while loop

💻 for Loop


for(int i=1; i<=5; i++){

    System.out.println(i);

}

💻 while Loop


int i = 1;

while(i <= 5){

    System.out.println(i);

    i++;

}

💻 do-while Loop


int i = 1;

do{

    System.out.println(i);

    i++;

}while(i <= 5);

⭐ Loop Control Statements

  • break
  • continue

🎯 Interview Question

Q. Difference between while and do-while?
Answer: The while loop checks the condition before execution. The do-while loop executes at least once before checking the condition.

11. Strings

A String is a sequence of characters used to store text. In Java, String objects are immutable, meaning their values cannot be changed after creation.

⭐ Common String Methods

  • length()
  • charAt()
  • substring()
  • equals()
  • equalsIgnoreCase()
  • toUpperCase()
  • toLowerCase()
  • contains()
  • replace()

💻 Example


String name = "Mashood";

System.out.println(name.length());

System.out.println(name.toUpperCase());

System.out.println(name.charAt(0));
💡 Tip

Use equals() to compare String values instead of ==.

🎯 Interview Question

Q. Are Strings mutable in Java?
Answer: No. String objects are immutable.

12. Methods

A method is a block of code that performs a specific task. Methods improve code reusability and readability.

⭐ Types

  • Predefined Methods
  • User-defined Methods

💻 Example


public class Main{

    static void greet(){

        System.out.println("Welcome");

    }

    public static void main(String[] args){

        greet();

    }

}

🎯 Interview Question

Q. Difference between Parameters and Arguments?
Answer: Parameters are declared in the method definition. Arguments are the actual values passed while calling the method.

13. Constructors

A constructor is a special method that is automatically called when an object is created. It has the same name as the class and does not have a return type.

⭐ Types

  • Default Constructor
  • Parameterized Constructor

💻 Example


class Student{

    String name;

    Student(String name){

        this.name = name;

    }

}

Student s = new Student("Mashood");
⚠ Important

Constructors cannot have a return type, not even void.

🎯 Interview Question

Q. Can a constructor be overloaded?
Answer: Yes. A class can have multiple constructors with different parameters.

14. this Keyword

The this keyword refers to the current object. It is commonly used to distinguish instance variables from local variables.

⭐ Uses of this

  • Refer current object
  • Access instance variables
  • Call another constructor
  • Pass current object as an argument

💻 Example


class Student{

    String name;

    Student(String name){

        this.name = name;

    }

}
💡 Tip

Use this.variableName when a local variable and instance variable have the same name.

🎯 Interview Question

Q. Why is the this keyword used?
Answer: It refers to the current object and helps distinguish instance variables from local variables.

15. static Keyword

The static keyword is used for variables, methods, and blocks that belong to the class rather than an object.

⭐ Uses of static

  • Static Variable
  • Static Method
  • Static Block

💻 Example


class Student{

    static String college = "CIT";

    String name;

}

public class Main{

    public static void main(String[] args){

        Student s1 = new Student();

        Student s2 = new Student();

        System.out.println(Student.college);

    }

}
💡 Tip

A static member belongs to the class, so it can be accessed using the class name.

🎯 Interview Question

Q. Can a static method access non-static variables directly?
Answer: No. A static method can directly access only static members.

16. Inheritance

Inheritance allows one class to acquire the properties and methods of another class. It promotes code reusability.

⭐ Types of Inheritance

  • Single
  • Multilevel
  • Hierarchical

Note: Java does not support multiple inheritance using classes.

💻 Example


class Animal{

    void sound(){

        System.out.println("Animal Sound");

    }

}

class Dog extends Animal{

    void bark(){

        System.out.println("Dog Barks");

    }

}

🎯 Interview Question

Q. Why doesn't Java support multiple inheritance through classes?
Answer: To avoid ambiguity (Diamond Problem). Java uses interfaces to achieve multiple inheritance.

17. Polymorphism

Polymorphism means "many forms". It allows the same method to perform different tasks.

⭐ Types

  • Method Overloading (Compile-time)
  • Method Overriding (Run-time)

📊 Comparison

Method Overloading Method Overriding
Same Class Parent & Child Class
Different Parameters Same Parameters
Compile-time Run-time

💻 Example


class Math{

    int add(int a,int b){

        return a+b;

    }

    int add(int a,int b,int c){

        return a+b+c;

    }

}

🎯 Interview Question

Q. Difference between Method Overloading and Method Overriding?
Answer: Overloading occurs in the same class with different parameters. Overriding occurs in parent and child classes with the same method signature.

18. Abstraction

Abstraction hides implementation details and shows only essential functionality. It can be achieved using abstract classes and interfaces.

💻 Example


abstract class Animal{

    abstract void sound();

}

class Dog extends Animal{

    void sound(){

        System.out.println("Bark");

    }

}
💡 Tip

Abstract classes cannot be instantiated directly.

🎯 Interview Question

Q. Can we create an object of an abstract class?
Answer: No. An abstract class cannot be instantiated.

19. Interface

An Interface is a blueprint of a class. It contains method declarations that implementing classes must define. It is used to achieve abstraction and multiple inheritance.

⭐ Key Points

  • Supports multiple inheritance.
  • Cannot be instantiated.
  • Methods are public and abstract by default.
  • Variables are public, static and final.

📊 Interface vs Abstract Class

Interface Abstract Class
Supports multiple inheritance Does not support multiple inheritance
No constructors Can have constructors
Methods are abstract by default Can have abstract and concrete methods

💻 Example


interface Animal{

    void sound();

}

class Dog implements Animal{

    public void sound(){

        System.out.println("Bark");

    }

}

🎯 Interview Question

Q. Why do we use interfaces?
Answer: To achieve abstraction and multiple inheritance.

20. Exception Handling

Exception Handling allows a program to handle runtime errors without crashing.

⭐ Keywords

  • try
  • catch
  • finally
  • throw
  • throws

💻 Example


try{

    int x = 10/0;

}catch(ArithmeticException e){

    System.out.println("Cannot divide by zero");

}finally{

    System.out.println("Program Ended");

}
💡 Tip

The finally block executes whether an exception occurs or not.

🎯 Interview Question

Q. Difference between throw and throws?
Answer: throw is used to explicitly throw an exception. throws declares exceptions that a method may throw.

23. Multithreading (Basics)

Multithreading allows multiple threads to execute simultaneously, improving application performance.

💻 Example


class MyThread extends Thread{

    public void run(){

        System.out.println("Thread Running");

    }

}

MyThread t = new MyThread();

t.start();
💡 Tip

Use start() instead of calling run() directly.

🎯 Interview Question

Q. Difference between start() and run()?
Answer: start() creates a new thread. run() executes like a normal method.
