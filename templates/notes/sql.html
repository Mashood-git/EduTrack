1. Introduction to SQL

SQL (Structured Query Language) is the standard language used to create, manage and retrieve data from relational databases.

⭐ Key Points

  • Used to communicate with databases
  • Stores and retrieves data efficiently
  • Works with MySQL, Oracle, SQL Server and PostgreSQL
  • Easy to learn

💻 Example


SELECT * FROM students;
💡 Tip

SQL is not case-sensitive, but writing keywords in uppercase improves readability.

🎯 Interview Question

Q. What does SQL stand for?
Answer: Structured Query Language.

2. Features of SQL

  • Simple and Easy to Learn
  • Standard Database Language
  • Fast Data Retrieval
  • Supports Security
  • Works with Large Databases
  • Portable

🎯 Interview Question

Q. Is SQL a programming language?
Answer: No. SQL is a database query language.

3. Database & DBMS

A database is an organized collection of data. A DBMS (Database Management System) is software used to create and manage databases.

Term Meaning
Database Collection of related data
DBMS Software to manage databases
RDBMS Relational DBMS that stores data in tables

🎯 Interview Question

Q. Difference between DBMS and RDBMS?
Answer: DBMS stores data. RDBMS stores related data in tables using relationships.

4. SQL Data Types

SQL data types define the type of data that can be stored in a table column.

⭐ Common Data Types

Data Type Description
INT Stores whole numbers
VARCHAR(n) Stores variable-length text
CHAR(n) Stores fixed-length text
FLOAT Stores decimal values
DATE Stores date
BOOLEAN Stores TRUE or FALSE

💻 Example


CREATE TABLE Student(

    id INT,

    name VARCHAR(50),

    marks FLOAT,

    dob DATE

);

🎯 Interview Question

Q. Difference between CHAR and VARCHAR?
Answer: CHAR stores fixed-length strings, whereas VARCHAR stores variable-length strings.

5. DDL (Data Definition Language)

DDL commands are used to create and modify database objects such as tables.

⭐ Common DDL Commands

Command Purpose
CREATE Create database or table
ALTER Modify table structure
DROP Delete table or database
TRUNCATE Delete all rows, keeps table
RENAME Rename database object

💻 Example


CREATE TABLE Student(

    id INT,

    name VARCHAR(50)

);


ALTER TABLE Student

ADD age INT;
⚠ Important

DROP removes the table completely. TRUNCATE removes only the data but keeps the table structure.

🎯 Interview Question

Q. Difference between DROP and TRUNCATE?
Answer: DROP deletes both table structure and data. TRUNCATE deletes only the data while keeping the table.

6. DML (Data Manipulation Language)

DML commands are used to insert, update and delete records from a table.

⭐ Common DML Commands

Command Purpose
INSERT Add new records
UPDATE Modify existing records
DELETE Remove records

💻 Insert Example


INSERT INTO Student

VALUES

(1,'Mashood',22);

💻 Update Example


UPDATE Student

SET age = 23

WHERE id = 1;

💻 Delete Example


DELETE FROM Student

WHERE id = 1;
💡 Tip

Always use the WHERE clause with UPDATE and DELETE to avoid modifying all records.

🎯 Interview Question

Q. What happens if you execute UPDATE without a WHERE clause?
Answer: All rows in the table will be updated.

7. DQL (Data Query Language)

DQL is used to retrieve data from a database. The main DQL command is SELECT.

⭐ Common SELECT Statements

  • SELECT *
  • SELECT column_name
  • DISTINCT
  • LIMIT
  • AS (Alias)

💻 Example


SELECT * FROM Student;


SELECT name, age

FROM Student;


SELECT DISTINCT city

FROM Student;
💡 Tip

Use SELECT * only when needed. Selecting specific columns improves performance.

🎯 Interview Question

Q. What is the purpose of DISTINCT?
Answer: It removes duplicate values from the result.

8. TCL (Transaction Control Language)

TCL commands are used to manage database transactions.

⭐ TCL Commands

Command Purpose
COMMIT Save changes permanently
ROLLBACK Undo changes
SAVEPOINT Create a rollback point

💻 Example


UPDATE Student

SET marks = 90

WHERE id = 1;

COMMIT;
⚠ Important

ROLLBACK works only before COMMIT.

🎯 Interview Question

Q. Difference between COMMIT and ROLLBACK?
Answer: COMMIT saves changes permanently. ROLLBACK undoes uncommitted changes.

9. Constraints

Constraints are rules applied to table columns to maintain data accuracy and integrity.

⭐ Common Constraints

Constraint Purpose
NOT NULL Cannot store NULL values
UNIQUE No duplicate values
PRIMARY KEY Unique identifier for each row
FOREIGN KEY Creates relationship between tables
CHECK Validates values
DEFAULT Assigns default value

💻 Example


CREATE TABLE Student(

    id INT PRIMARY KEY,

    name VARCHAR(50) NOT NULL,

    age INT CHECK(age >= 18)

);

🎯 Interview Question

Q. Difference between PRIMARY KEY and UNIQUE?
Answer: PRIMARY KEY uniquely identifies each row and cannot contain NULL values. UNIQUE also prevents duplicates but generally allows a NULL value depending on the database system.

10. WHERE Clause

The WHERE clause filters records based on a specified condition.

💻 Example


SELECT *

FROM Student

WHERE age > 20;

⭐ Operators Used with WHERE

  • =
  • >
  • <
  • >=
  • <=
  • != or <>
  • AND
  • OR
  • NOT
  • IN
  • BETWEEN
  • LIKE

💻 Example


SELECT *

FROM Student

WHERE city = 'Mysore'

AND age >= 20;
💡 Tip

Always use the WHERE clause with UPDATE and DELETE to avoid affecting all records.

🎯 Interview Question

Q. Which operator is used to search for patterns in SQL?
Answer: The LIKE operator.

11. ORDER BY

The ORDER BY clause is used to sort the result set in ascending or descending order.

⭐ Syntax


SELECT column_name

FROM table_name

ORDER BY column_name ASC;

💻 Example


SELECT *

FROM Student

ORDER BY marks DESC;
💡 Tip

ASC is the default sorting order. Use DESC for descending order.

🎯 Interview Question

Q. What is the default sorting order in SQL?
Answer: Ascending (ASC).

12. GROUP BY

The GROUP BY clause groups rows having the same values into summary rows.

💻 Example


SELECT department,

COUNT(*)

FROM Employee

GROUP BY department;
💡 Tip

GROUP BY is commonly used with aggregate functions like COUNT(), SUM() and AVG().

🎯 Interview Question

Q. Why is GROUP BY used?
Answer: To group rows and perform aggregate calculations on each group.

13. JOINS

Joins combine data from two or more tables based on a related column.

⭐ Types of Joins

Join Description
INNER JOIN Returns matching records from both tables.
LEFT JOIN Returns all records from the left table and matching records from the right table.
RIGHT JOIN Returns all records from the right table and matching records from the left table.
FULL JOIN Returns all matching and non-matching records from both tables.

💻 Example


SELECT Student.name,

Course.course_name

FROM Student

INNER JOIN Course

ON Student.course_id = Course.id;
⚠ Important

INNER JOIN returns only matching rows. LEFT JOIN returns all rows from the left table.

🎯 Interview Question

Q. Difference between INNER JOIN and LEFT JOIN?
Answer: INNER JOIN returns only matching rows. LEFT JOIN returns all rows from the left table and matching rows from the right table.

14. Aggregate Functions

Aggregate functions perform calculations on multiple rows and return a single value.

Function Purpose
COUNT() Counts rows
SUM() Adds values
AVG() Average value
MIN() Smallest value
MAX() Largest value

💻 Example


SELECT AVG(marks)

FROM Student;

🎯 Interview Question

Q. Which function returns the total number of rows?
Answer: COUNT()

15. Subqueries

A subquery is a query written inside another SQL query.

💻 Example


SELECT name

FROM Student

WHERE marks >

(

SELECT AVG(marks)

FROM Student

);
💡 Tip

Subqueries can be used inside SELECT, INSERT, UPDATE and DELETE statements.

🎯 Interview Question

Q. What is a Subquery?
Answer: A query nested inside another SQL query.
