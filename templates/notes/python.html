1. Introduction to Python

Python is a high-level, interpreted programming language created by Guido van Rossum and released in 1991. It is known for its simple syntax, readability, and wide range of applications.

⭐ Key Points

  • Easy to learn and use
  • Open-source and free
  • Platform independent
  • Supports Object-Oriented Programming
  • Large collection of libraries

💻 Example


print("Hello, World!")

⚠ Important

Python is case-sensitive. For example, print() and Print() are different.

🎯 Interview Question

Q. Who developed Python?
Answer: Guido van Rossum.

2. Features of Python

  • Simple and readable syntax
  • Interpreted language
  • Dynamically typed
  • Cross-platform support
  • Large standard library
  • Supports multiple programming paradigms

💡 Applications

  • Web Development
  • Artificial Intelligence
  • Machine Learning
  • Automation
  • Data Science
  • Cyber Security

🎯 Interview Question

Q. Is Python compiled or interpreted?
Answer: Python is an interpreted language.

3. Variables

A variable is a named container used to store data values. Python automatically assigns the data type based on the value.

⭐ Rules

  • Must start with a letter or underscore (_)
  • Cannot start with a number
  • Case-sensitive (age and Age are different)
  • Use meaningful variable names

💻 Example


name = "Mashood"
age = 22
height = 6.0
is_student = True

🎯 Interview Question

Q. Does Python require variable declaration?
Answer: No. Python automatically creates variables when a value is assigned.

4. Data Types

A data type specifies the type of value stored in a variable.

Data Type Example
int 10
float 3.14
str "Hello"
bool True / False
list [1,2,3]
tuple (1,2,3)
set {1,2,3}
dict {"name":"Mashood"}

💻 Example


x = 10
print(type(x))
Output 

<class 'int'>

5. Type Casting

Type casting means converting one data type into another.

⭐ Types

  • Implicit Type Casting (Automatic)
  • Explicit Type Casting (Manual)

💻 Example


age = "22"

age = int(age)

print(age + 5)
Output 

27

🎯 Interview Question

Q. What is the difference between implicit and explicit type casting?
Answer: Implicit conversion is done automatically by Python, whereas explicit conversion is done by the programmer using functions like int(), float(), and str().

6. Operators

Operators are symbols used to perform operations on variables and values.

⭐ Types of Operators

  • Arithmetic (+, -, *, /, %, //, **)
  • Comparison (==, !=, >, <, >=, <=)
  • Logical (and, or, not)
  • Assignment (=, +=, -=)
  • Membership (in, not in)
  • Identity (is, is not)

💻 Example


a = 10
b = 3

print(a + b)
print(a % b)
print(a > b)

⚠ Important

  • = → Assignment
  • == → Comparison

🎯 Interview Question

Q. Difference between == and is ?
Answer: == compares values, is compares memory location (object identity).

7. Input & Output

Python uses input() to accept user input and print() to display output.

💻 Example


name = input("Enter your name: ")

print("Welcome", name)

⚠ Important

The input() function always returns a string. Use int() or float() when numerical input is required. 


age = int(input("Enter Age: "))

🎯 Interview Question

Q. What is the return type of input()?
Answer: String (str)

8. Conditional Statements

Conditional statements help execute different blocks of code based on conditions.

⭐ Types

  • if
  • if-else
  • if-elif-else
  • Nested if

💻 Example


age = 20

if age >= 18:
    print("Eligible")
else:
    print("Not Eligible")

⚠ Important

Python uses indentation instead of curly braces ({ }).

🎯 Interview Question

Q. What is indentation in Python?
Answer: Indentation defines the block of code and is mandatory.

9. Loops

Loops are used to execute a block of code repeatedly.

⭐ Types

  • for loop
  • while loop

💻 for Loop


for i in range(5):
    print(i)

💻 while Loop


count = 1

while count <= 5:
    print(count)
    count += 1

⭐ Loop Control Statements

  • break
  • continue
  • pass

🎯 Interview Question

Q. Difference between for and while loop?
Answer: For loop is used when the number of iterations is known. While loop is used when the condition controls the iterations.

10. Strings

A string is a sequence of characters enclosed in single or double quotes.

💻 Example


name = "Mashood"

print(name.upper())
print(name.lower())
print(len(name))

⭐ Common String Methods

  • upper()
  • lower()
  • strip()
  • replace()
  • split()
  • find()
  • count()

🎯 Interview Question

Q. Are strings mutable in Python?
Answer: No. Strings are immutable.

11. Lists

A list is an ordered, mutable collection that can store multiple values of different data types.

⭐ Features

  • Ordered
  • Mutable (Can be modified)
  • Allows duplicate values
  • Supports indexing

💻 Example


fruits = ["Apple", "Mango", "Orange"]

print(fruits[0])

fruits.append("Banana")

print(fruits)

⭐ Common Methods

  • append()
  • insert()
  • remove()
  • pop()
  • sort()
  • reverse()

🎯 Interview Question

Q. Are lists mutable?
Answer: Yes.

12. Tuples

A tuple is an ordered, immutable collection of elements.

⭐ Features

  • Ordered
  • Immutable
  • Allows duplicates

💻 Example


numbers = (10, 20, 30)

print(numbers[1])

⭐ Common Methods

  • count()
  • index()

🎯 Interview Question

Q. Difference between List and Tuple?
Answer: Lists are mutable, whereas tuples are immutable.

13. Sets

A set is an unordered collection of unique elements.

⭐ Features

  • Unordered
  • No duplicate values
  • Mutable

💻 Example


numbers = {1,2,3,3,4}

print(numbers)
Output 

{1,2,3,4}

⭐ Common Methods

  • add()
  • remove()
  • discard()
  • clear()

🎯 Interview Question

Q. Why do we use Sets?
Answer: To store unique values and remove duplicates.

14. Dictionaries

A dictionary stores data in key-value pairs.

⭐ Features

  • Mutable
  • Keys are unique
  • Fast data lookup

💻 Example


student = {

    "name":"Mashood",

    "age":22,

    "city":"Mysore"

}

print(student["name"])

⭐ Common Methods

  • keys()
  • values()
  • items()
  • get()
  • update()
  • pop()

🎯 Interview Question

Q. Can a dictionary have duplicate keys?
Answer: No. Dictionary keys must be unique.

15. Functions

A function is a block of reusable code that performs a specific task.

⭐ Advantages

  • Code Reusability
  • Reduces Code Duplication
  • Easy to Maintain

💻 Example


def greet(name):
    return "Hello " + name

print(greet("Mashood"))

⭐ Types

  • Built-in Functions
  • User-defined Functions

🎯 Interview Question

Q. Difference between a parameter and an argument?
Answer: Parameters are defined in the function, while arguments are the values passed during the function call.

16. Lambda Functions

A lambda function is a small anonymous function written in a single line.

💻 Example


square = lambda x: x * x

print(square(5))
Output 

25

🎯 Interview Question

Q. When should Lambda functions be used?
Answer: For short, simple functions that are used only once.

17. File Handling

File handling is used to read from and write data to files.

⭐ File Modes

  • r → Read
  • w → Write
  • a → Append
  • x → Create

💻 Example


file = open("data.txt", "r")

print(file.read())

file.close()

🎯 Interview Question

Q. Why should we close a file?
Answer: To free system resources after use.

18. Exception Handling

Exception handling prevents the program from crashing due to runtime errors.

⭐ Keywords

  • try
  • except
  • finally
  • raise

💻 Example


try:
    print(10/0)

except ZeroDivisionError:
    print("Cannot divide by zero")

🎯 Interview Question

Q. What is an Exception?
Answer: An unexpected event that interrupts normal program execution.

19. Object-Oriented Programming (OOP)

OOP is a programming paradigm based on classes and objects.

⭐ Four Pillars

  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction

💻 Example


class Student:

    def __init__(self, name):
        self.name = name

student = Student("Mashood")

print(student.name)

🎯 Interview Question

Q. What is Inheritance?
Answer: It allows one class to inherit properties and methods from another class.

20. Modules & Packages

A module is a Python file containing functions and variables. A package is a collection of modules.

💻 Example


import math

print(math.sqrt(25))

🎯 Interview Question

Q. Difference between Module and Package?
Answer: Module = Single Python file. Package = Collection of Modules.
